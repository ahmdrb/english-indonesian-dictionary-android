# English ↔ Indonesian Offline Dictionary

An offline-first Android dictionary project using a native Android
WebView interface and a planned local SQLite dictionary database.

## Current stage

The initial application shell is under development. Dictionary lookup
and third-party dictionary datasets have not yet been integrated.

## Build

GitHub Actions builds a debug APK when changes are pushed to `main`,
or when the workflow is started manually. The APK is uploaded as an
Actions artifact.

## Data policy

Dictionary sources must be reviewed individually for redistribution
rights, attribution, license compatibility, version and checksum before
being included in a release. Source provenance must be retained.
